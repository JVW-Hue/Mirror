FOIA Request Results — Helix Technologies

Request filed: June 2020
Response received: September 2020
Pages responsive: 2,847 of 14,000+

Summary

A FOIA request was filed for all documents related to Project MIRROR, Helix Technologies, and any federal contracts involving behavioral prediction models.

The response contained 2,847 pages of mostly redacted documents. 11,153 pages were withheld entirely under Exemption 7 (law enforcement) and Exemption 4 (trade secrets).

Notable Unredacted Content

Page 1,247: A single line of text that reads:

"Subject count: 2,304,891. Model accuracy: 96%. False positives: 92,196. Reference cohort: 2,847."

This matches the numbers we've seen elsewhere. 2,304,891 subjects. 92,196 false positives. 2,847 reference cohort.

The reference cohort number is the same as the number of responsive pages in this FOIA response. Coincidence?
